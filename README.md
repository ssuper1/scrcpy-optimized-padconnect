# scrcpy-优化(padconnect)

基于 **scrcpy-android 0.5** 修改的 Android 手机控制平板工具。当前版本：**0.6.14-phone**。

原项目主以下不足有些影响本人使用：

1. 被控制端 Wi-Fi 断开，或无线调试关闭后重新开启，需要重新输入连接地址（关键）。
2. 平板与手机屏幕比例不同，导致屏幕利用率低。
3. 无法旋转屏幕。
4. 无法调整画面缩放比例。

主要改进手机控制平板时的使用体验：平板与手机比例不同导致画面太小、操作按钮占空间，以及常用应用切换不方便。无线调试配对、ADB 连接、音视频传输等基础能力来自上游项目。

## 在原版上的主要改进详情

### 已配对设备自动发现新地址

打开设备页自动搜索已保存设备，连接及断线重连时重新发现无线调试的当前 IP 和连接端口，使用已有配对连接。只有发现的设备标识与保存记录一致，才会尝试新地址，并在 ADB 连接成功后更新记录。连接后的系统属性读取仅作补充检查，平板不提供该属性时仍保留配对标识并继续连接；返回明确不同的标识时拒绝连接。

0.6.12 修复 0.6.11 在部分系统发现新端口后，因无法读取设备标识属性而报「不能确定发现的设备」并主动断开的问题。连接失败的原因现在保留在投屏页，方便查看和复制。

- 新配对时保存平板返回的设备标识，后续换 IP 或连接端口通常无需重新输入配对码。
- 旧版本的记录在成功连接且系统属性可读时补齐标识；如果旧端口已经失效，长按设备 →「修改连接地址」，填入无线调试主页的新地址再连接。若旧记录没有标识且系统属性始终不可读，需重新配对一次以保存配对返回的标识；已经显示「已发现」的记录无需重新配对。
- 支持「重新搜索」；发现不到时回退到已保存地址，也可以手动改地址，保留配对。
- 自动发现依赖局域网 mDNS 和平板无线调试；无法跨网络发现，也不能恢复已被平板撤销的配对。

### 手机比例的独立屏幕

新增默认开启的「手机模式」，在平板上创建与控制手机比例匹配的独立屏幕，让应用使用手机形状的显示区域，减少直接缩放平板画面产生的大面积留白。应用仍在平板上运行。

保留「原始比例」模式，需要同步平板主屏或遇到应用兼容性问题时，可以从菜单切回。

0.6.14 按使用反馈移除「平板桌面」入口，保留手动切换显示比例。
手机模式里的系统 Home 仍由平板的副屏桌面支持决定，遇到空白可从菜单重新选择应用。

### 应用选择、搜索与收藏置顶

新增「应用与收藏」入口和「应用 / 收藏」选择框，可以直接在控制手机上选择平板应用，不必到平板上手动操作。

- 支持按应用名称或包名搜索，并记住上次打开的应用。
- 点击应用右侧星标即可收藏或取消收藏，收藏项单独分组并排在列表最前面。
- 搜索时优先显示匹配的收藏项；收藏保存在控制手机，退出或重新连接后仍保留。
- 点击应用名称打开应用；点击星标只改变收藏，不启动应用，也不关闭选择框。

选择框改为圆角面板、带搜索图标的输入框和紧凑应用卡片，移除了标题下方的长段说明。
应用卡片显示从平板读取的真实启动图标，支持普通、矢量及自适应图标；图标在后台解码并随列表缓存，读取失败时使用通用应用图标。

### 全屏显示与侧边菜单

投屏时隐藏控制手机的顶部状态栏和底部手势条，并移除底部固定按钮栏，把更多空间交给远程画面。从屏幕边缘滑动仍可临时唤出本机系统导航。

操作入口改为可拖动的侧边把手：可上下移动、换到另一侧，松手自动贴边并保存位置，闲置后自动淡化。点击后可使用远程返回、应用选择、屏幕旋转、显示模式、界面大小和断开连接等功能。

0.6.14 为菜单增加统一的矢量线条图标、圆角深色面板和分组分隔线。
「应用与收藏」「手机比例」「平板原始比例」使用简短名称；当前显示模式有单选标记，
断开时远程返回和应用选择不可用。菜单在重连或离开投屏时关闭。

### 界面大小调整与屏幕旋转

- 提供 **75%、85%、100%、125%、150%** 五档文字与按钮大小，通过调整独立屏幕的显示密度实现；选择后会重新连接并应用。
- 调整只针对独立屏幕，不修改平板主屏分辨率、密度或全局字体设置。
- 新增「旋转屏幕」菜单，即使控制手机关闭了自动旋转，也可以切换投屏页面横竖屏。手机模式会同步调整独立屏幕比例，无需重新连接；原始比例模式仅旋转控制手机上的投屏页面。

### 渲染、应用查询和内置服务修复

- 将应用渲染尺寸与视频传输分辨率分开，减少降低传输分辨率时部分界面、图标被放大的问题。
- 连接时检查独立屏幕的实际显示密度，必要时重新应用；无法确认时给出提示。
- 修复应用查询依赖的服务文件被清理后，导致无法获取平板应用列表的问题。
- 内置根据本地修改源码构建的 scrcpy 4.1 服务，并在客户端构建时检查版本与 SHA-256，减少服务文件版本不匹配的问题。

同时补齐根工程的 Android Studio 运行配置、构建脚本和自动化测试。0.6.14 已通过 138 项客户端测试、17 项 ADB 测试，以及 debug / release 构建和 lint 检查。本版未修改内置服务，沿用 0.6.10 已通过 51 项服务端测试的服务文件。本轮未进行设备界面验证。

## 使用方式与当前限制

将本项目 APK 安装在控制手机上，在平板上开启开发者选项和无线调试，完成配对后连接。投屏后点击侧边把手，通过「应用与收藏」打开应用和设置收藏；可选择「手机比例」或「平板原始比例」。

- 手机模式使用独立屏幕，平板主屏切换应用不会自动同步到这里；需要同步主屏时选择「原始比例」。
- 部分系统、游戏或固定比例应用可能限制独立屏幕，或仍有留白，可尝试原始比例模式。
- 已允许独立屏幕显示系统装饰，但顶部状态栏仍可能缺失，不能保证与平板主屏一致。隐藏控制手机的小白条与平板端系统栏分别处理。

更详细的功能说明和版本记录见 [PHONE-MODE.md](PHONE-MODE.md)。

## 开发与构建

<details>
<summary>展开 Android Studio、构建命令和工程结构说明</summary>

### Android Studio

打开本仓库根目录，等待 Gradle 同步完成，选择运行配置 **scrcpy 手机模式**（模块 `remote`）。不要选择根目录原有的 `app` 示例模块。

- JDK 21（Gradle 工具链配置可以自动下载）。
- Android SDK Platform 36、Build Tools 36.1.0。
- `local.properties` 配置自己的 `sdk.dir`，或设置 `ANDROID_HOME`。
- 首次构建需要网络下载 Gradle 和 Maven/JitPack 依赖。

开发版包名为 `invalid.lena.scrfix.debug`，可与发布版 `invalid.lena.scrfix` 共存；开发版需要单独配对。

### 构建和检查

Windows PowerShell：

```powershell
.\gradlew.bat :remote:assembleDebug :remote:testDebugUnitTest :adb:testDebugUnitTest :remote:lintDebug --console=plain --no-configuration-cache
```

APK 位于 `scrcpy-android/app/build/outputs/apk/debug/`。

发布构建：

```powershell
.\gradlew.bat :remote:assembleRelease :remote:lintRelease --console=plain --no-configuration-cache
```

发布签名通过环境变量 `KEYSTORE_PATH`、`KEYSTORE_PASS`、`KEY_ALIAS`、`KEY_PASS` 配置；四项齐全时 Gradle 会签名，否则生成未签名的发布包。仓库不包含签名密钥；重新生成密钥签名的包不能直接覆盖以前使用另一把密钥签名的安装包。

`scripts/build-phone.ps1` 保留原维护者本地测试签名流程，默认从用户目录的 `.codex/app-signing/padconnect-repair.p12` 读取密钥；一般开发使用上述 Gradle 命令即可。

### 内置服务

仓库包含修改后的 scrcpy 4.1 服务源码和对应的内置服务文件，因此首次客户端构建不需要单独编译服务。客户端构建会检查服务文件 SHA-256 和版本标记。

修改服务源码后，先重新构建服务，再构建客户端：

```powershell
.\scripts\build-server.ps1
.\gradlew.bat :remote:assembleDebug --no-configuration-cache
```

脚本从 `ANDROID_HOME`、`ANDROID_SDK_ROOT`、根目录 `local.properties` 或 Windows 默认 SDK 目录查找 SDK，也可显式传入 `-SdkDirectory`。服务脚本同时运行服务端单元测试和 lint。

### 目录

- `scrcpy-android/app/`：实际客户端，对应根工程的 `:remote`。
- `scrcpy-android/vendor/libadb-android/`：ADB 库，对应 `:adb`。
- `scrcpy-android/vendor/scrcpy/`：完整 vendored scrcpy 源码，包含服务端修改。
- `app/`：最初的 Android 示例工程，保留供参考；其依赖和构建要求独立于 `remote`。
- `PHONE-MODE.md`：功能、行为和历史验证说明。
- `NOTICE`：上游来源、版本和本地修改说明。

源码以普通文件保存，不需要初始化 Git 子模块。原上游仓库内的构建说明和工具仍保留，构建本版本请以本文件的根工程命令为准。
